工作原理

一条可以审计的透明流程，不是黑箱。

1

扫描可信来源

每周一、周三和周五从固定的、人工筛选过的学术来源列表抓取信息，包括学会、研究机构和成熟暑校。

2

提取证据

规则提取日期、截止时间、资助、费用、地点和形式，并保留来源文本方便核验。

3

应用严格筛选

只有真实的线下科研训练项目，在申请开放且费用或资助条件可接受时，才会被标为完全符合；学科方向不受限制。

4

每日发布

结果会提交并发布到这个静态网站，方便公开查看。

关于与方法

说明它是什么、覆盖什么，以及边界在哪里。

它是什么

Summa 是一个开源的固定来源扫描器，使用规则提取，并为每个字段保留证据。它不是全网自动爬虫。

覆盖领域

不限制学科方向。所有领域统一执行截止日期、时长、费用或资助、线下形式和官方证据规则。

什么算符合

  • 有资助，或低费用/免费，而不是昂贵付费课程。
  • 线下参与；纯线上活动会被排除。
  • 申请截止日期仍未过去。
  • 是真正的研究暑校、训练营、田野学校或短课程，而不是会议或完整学位项目。
  • 是真正的学术研究训练项目，不限制学科。

证据与透明度

每个可提取字段都会尽量保留来源证据。近似匹配会单独展示，不会被当作完全符合。

常见问题

关于范围、更新和参与方式的简短回答。

它免费吗？

免费，而且开源。默认流程没有付费墙、不需要账号，也不依赖付费搜索 API。

多久更新一次？

网站每天重建以刷新截止日期状态；来源页面在每周一、周三和周五重新抓取。

为什么有些已扫描项目没有公开展示？

信息不完整或未通过规则的记录只保留在维护者审核队列中。公开页面只展示已确认属于科研训练、申请开放、费用或资助可接受、日期明确且包含线下参与的机会；学科方向不受限制。

怎么避免低质量信息？

它只读取人工维护的可信学术来源列表，不做开放网络泛爬。

我可以建议来源吗？

可以。在 GitHub issue 里提交来源和活动页面，维护者可以把它加入来源列表。
